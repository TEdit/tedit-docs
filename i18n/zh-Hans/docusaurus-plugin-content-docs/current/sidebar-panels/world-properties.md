# 世界属性

世界属性面板用于查看并深度编辑地图世界的元数据、游戏通关与击杀进度标志以及 NPC 状态。

![世界属性](/img/v5/sidebar-panels/sidebar-world-properties.png)

## 各分组详解

### 世界基础信息

- **世界名称** — 重命名你的世界
- **世界种子** — 查看当前世界的生成种子码
- **世界 ID（World ID）** — 独特的数字身份标识
- **地表与基岩层阈值** — 精确调整地表线与底层基岩层的分界高度

### 时间与天气 {#time--weather}

- **时间** — 包含泰拉瑞亚 24 小时全天日夜循环的渐变滑块。拖拽滑块即可设定任意时分秒——渐变色实时反映该时刻的天空色调。右侧输入框以 `h:mm AM/PM` 格式实时展示并支持直接键盘键入。
- **月相** — 在八种月相之间自由切换
- **Blood Moon (血月) / Eclipse（日食）** — 一键开启或关闭特殊天象事件
- **Rain (下雨) / Sandstorm（沙尘暴）** — 开启或关闭极端天气

### Boss击杀进度

勾选或取消勾选各大 Boss 的击杀状态。这会直接影响 NPC 的生成、敌怪掉落以及困难模式的启用。

![Boss击杀标记](/img/v5/sidebar-panels/sidebar-worldproperties-scroll1.png)

### 入侵与特殊事件

- **哥布林军队 / 海盗入侵 / 火星暴乱**
- **陨石坠落标记**
- **已砸碎暗影珠/猩红之心计数**

### NPC 居民列表

集中管理城镇 NPC — 添加、驱逐及设定其房屋分配。

![NPC 属性详情](/img/v5/sidebar-panels/sidebar-worldproperties-scroll3.png)

:::tip 技巧
使用左侧工具栏的 [点位工具](../interface/toolbar.md#point-tool-p) 可以在地图画布上直观插旗标记 NPC 的房屋入住点。
:::
