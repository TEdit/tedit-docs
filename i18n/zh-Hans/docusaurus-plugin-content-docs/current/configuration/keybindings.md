# 快捷键

TEdit 5 支持对大多数操作自定义键盘快捷键。

## 默认快捷键

### 工具

| 快捷键 | 工具 |
|---|---|
| `A` | 箭头工具 |
| `S` | 选区工具 |
| `E` | 铅笔工具 |
| `B` | 笔刷工具 |
| `F` | 填充工具 |
| `R` | 吸管工具（按住临时取色，单击切换） |
| `P` | 点位工具 |
| `T` | 物体工具 |

### 文件操作

| 快捷键 | 操作 |
|---|---|
| `Ctrl+O` | 打开世界 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |

### 选区与剪贴板

| 快捷键 | 操作 |
|---|---|
| `Ctrl+C` | 复制选区 |
| `Ctrl+V` | 粘贴 |
| `Ctrl+D` | 取消选区 |
| `Ctrl+A` | 全选 |

### 浮动粘贴

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Q` | 顺时针旋转 90° |
| `Ctrl+Shift+Q` | 逆时针旋转 90° |
| `Ctrl+H` | 水平翻转 |
| `Ctrl+Shift+H` | 垂直翻转 |
| `Enter` | 确认粘贴 |
| `Esc` | 取消粘贴 |

### 视图

| 快捷键 | 操作 |
|---|---|
| `Ctrl+=` | 放大 |
| `Ctrl+-` | 缩小 |
| 方向键 | 平移视野 |
