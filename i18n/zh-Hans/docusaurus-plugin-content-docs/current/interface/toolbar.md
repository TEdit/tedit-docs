# 工具栏

工具栏位于编辑器最左侧。点击选择对应的工具后，即可在中央地图画布上交互操作。

![工具栏标注](/img/v5/interface/toolbar-all-labeled.png)

## 箭头工具 `[A]` {#arrow-tool-a}

默认的指针工具。用于检查地图物块信息而不对地图做任何更改。

| 操作动作 | 触发效果 |
|---|---|
| 悬停鼠标 | 在底部 [状态栏](status-bar.md) 显示光标所指物块的详细信息 |
| 鼠标右键 | 打开点击处的宝箱、标牌或图格实体编辑器 |

## 选区工具 `[S]` {#selection-tool-s}

在地图上拉出矩形选择区域。

| 操作动作 | 触发效果 |
|---|---|
| 鼠标左键 + 拖拽 | 框选指定区域 |
| Shift + 鼠标左键 + 拖拽 | 追加扩展当前选区 |
| 鼠标右键 或 `Ctrl+D` | 取消/清除当前选区 |
| Ctrl + 鼠标右键 | 恢复刚才取消的选区 |
| `Ctrl+C` | 复制当前选区至 [剪贴板](../sidebar-panels/clipboard.md) |

当选区激活时，绘制操作将被严格限制在选区内部生效。

### 导出选区为 PNG 图片

当存在激活选区时，你可以通过 **编辑 → Export Selection** 菜单或画布上方浮现的选区工具条将其导出为高清 PNG 图片。支持四种导出缩放规格：

| 缩放比例 | 每个物块像素 | 说明解释 |
|---|---|---|
| **像素地图（1×）** | 1×1 | 基于小地图物块颜色的极速概览（仅消耗 CPU） |
| **四分之一纹理（4×）** | 4×4 | 紧凑型渲染预览图 |
| **半尺寸纹理（8×）** | 8×8 | 画质与文件体积兼顾的平衡规格 |
| **全尺寸纹理（16×）** | 16×16 | 原生游戏分辨率渲染，完整呈现墙壁、物块、液体和电线 |

纹理渲染模式（4×, 8×, 16×）与编辑器画布呈现完全一致的真实画质，包括反色漆效果和原版物块材质。超大选区导出时会自动分带渲染，以控制在 GPU 显存限制之内。

## 吸管工具 `[R]` {#picker-tool-r}

从地图画布上直接吸取物块、墙壁或液体的属性。

| 操作动作 | 触发效果 |
|---|---|
| 鼠标左键 | 吸取光标处的物块、墙壁和液体类型 |
| 鼠标右键 | 将光标处类型吸取为遮罩 |

**按住即吸取（快捷机制）：** 按住键盘 `R` 键可临时切换为吸管工具，点击吸取后松开 `R` 键，将立即自动切回刚才使用的工具；若仅轻敲一下 `R` 键，则会永久切换至吸管工具。

## 铅笔工具 `[E]` {#pencil-tool-e}

单格放置物块。专为精细细节打造。

| 操作动作 | 触发效果 |
|---|---|
| 鼠标左键 + 拖拽 | 徒手自由绘制 |
| Shift + 鼠标左键 | 绘制到点击处的笔直单线段 |
| 鼠标右键 + 拖拽 | 绘制水平直线 |
| 左右键同时按住 + 拖拽 | 绘制垂直直线 |
| Alt + 鼠标左键 | [电线高亮追踪](#wire-trace-highlight)（在电线模式下） |

在电线绘制模式下，按下 `Shift+W` 可激活 [单线电线布线](wire-routing.md)——类似于 CAD 的点击式 90° 直角与 45° 斜角规整布线。

### 连续折线绘制 (Shift+点击) {#polyline-drawing-shiftclick}

按住 **Shift** 键并依次点击画布上的不同点位，即可绘制连续的平直折线。每次点击锁定前一段终点并开启下一段。适用于铅笔、笔刷和环境演变工具。松开 Shift 键即结束折线绘制。

## 笔刷工具 `[B]` {#brush-tool-b}

使用可自定义大小和几何形状的笔刷大面积绘制。详见 [笔刷设置](brush-settings.md)。

控制方式与铅笔工具一致，但影响范围根据笔刷尺寸扩展。同样支持按住 Shift 连续折线绘制，以及 Alt + 左键点击 [电线追踪高亮](#wire-trace-highlight)。

在电线绘制模式下，按下 `Shift+W` 可启用 [总线电线布线](wire-routing.md#bus-routing-brush-tool)——在笔刷覆盖宽度内以标准间距并排绘制多条平行电线。

## 填充工具 `[F]` {#fill-tool-f}

泛洪填充相同类型的相连相通区域。

| 操作动作 | 触发效果 |
|---|---|
| 鼠标左键 | 泛洪填充相连的匹配物块区域 |
| 在选区内左键点击 | 填充仅限于当前框选选区内 |

## 点位工具 `[P]` {#point-tool-p}

放置世界出生点和 NPC 入住房屋点位。

![特殊兴趣点位](/img/v5/interface/special-interest-points.png)

从操作栏下拉菜单中选择点位类型（世界出生点、地牢入口、各 NPC 房屋点、各队伍出生点等），在地图上单击左键即可放置。

## 物体工具 `[T]` {#sprite-tool-t}

放置家具、装饰以及各类多格物体。

| 操作动作 | 触发效果 |
|---|---|
| 鼠标左键 | 放置物体 |
| 鼠标左键 + 拖拽 | 连续排布放置 1x1 规格的小装饰 |

配合使用[物体面板](../sidebar-panels/sprites.md)选择具体的分类和样式变体。

## 环境演变工具 {#morph-tool}

将现有物块和背景墙批量转换为指定的生物群系类型。

![环境演变设置](/img/v5/interface/morph-tool-options.png)

仅对已有物块生效，不会填充空白空气。不同深度层级（天空、地表泥土、岩石、地狱层）会自动演变对应的地层特色。支持 Shift + 点击 [绘制连续折线](#polyline-drawing-shiftclick)。

支持选项：
- **目标生物群系** — 净化（纯净）、腐化、猩红、神圣、发光蘑菇、丛林、森林、雪原或沙漠
- **基础物块 / 邪恶物块 / 苔藓 / 物体** — 勾选控制具体哪些元素参与演变转换

当勾选 **物体** 时，草丛、藤蔓、火把、恶魔祭坛/猩红祭坛、暗影珠/猩红之心等多物块装饰将自动替换为对应生物群系的变体。支持双向无损转换，结构细节完整保留。

## 粘贴工具 {#paste-tool}

使用 `Ctrl+V` 或在 [剪贴板面板](../sidebar-panels/clipboard.md) 中点击结构图上的 **粘贴** 按钮激活。

![浮动粘贴](/img/v5/interface/paste.png)

| 操作动作 | 触发效果 |
|---|---|
| 鼠标左键 | 在地图上放置浮动粘贴预览图层 |
| 在预览图层内拖拽 | 移动对齐位置 |
| 拖拉四周控制手柄 | 自由拉伸缩放（最近邻算法采样） |
| `Ctrl+Q` / `Ctrl+Shift+Q` | 顺时针 / 逆时针旋转 90° |
| `Ctrl+H` / `Ctrl+Shift+H` | 水平翻转 / 垂直翻转 |
| `Enter` 回车键 | 确认接受（正式写入世界） |
| `Esc` 退出键 | 取消放弃本次粘贴 |

粘贴工具栏提供了可直接手动输入的 X、Y、W、H 坐标和宽高尺寸。完整说明详见 [剪贴板 — 浮动粘贴](../sidebar-panels/clipboard.md#floating-paste)。

## 电线高亮追踪 {#wire-trace-highlight}

在含有电线的物块上按住 **Alt + 鼠标左键**，编辑器会自动高亮显示整条相连通的电线回路。TEdit 从点击处采用感知朝向的广度优先搜索（BFS）溯源，并遵循**分线盒**的交叉隔离规则——分线盒两侧独立的电线会被分别追踪。

追踪到的电线回路将以对应的彩色叠加高亮显示（红、蓝、绿、黄）。如果在 [电线模式](paint-mode.md#wire-mode) 选择器中选中了特定颜色，TEdit 将定向追踪该颜色；否则追踪点击物块上发现的第一种电线。

切换当前工具或在空白处 Alt + 点击即可清除高亮状态。

该追踪功能适用于箭头工具、铅笔工具和笔刷工具。

## 敲锤工具 {#hammer-tool}

基于笔刷范围的大面积锤击工具。使用与笔刷工具相同的笔刷形状与尺寸，一键对覆盖区域批量应用锤击坡度变换。
