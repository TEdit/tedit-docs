# 损坏世界修复

当您的泰拉瑞亚世界文件受损导致在游戏内无法加载时，TEdit 或许依然能够打开并对其进行修复。

## 修复步骤

1. **在 TEdit 中打开世界** — TEdit 有时能够打开泰拉瑞亚游戏无法读取的世界
2. **检查损坏情况** — 查看是否有丢失的区块、混乱的物块或地形断层空洞
3. **手动修补** — 使用笔刷和填充工具修补受损区域
4. **另存为新文件** — 切勿直接覆盖原始文件，以防需要重新尝试

## 泰拉瑞亚原版备份文件

泰拉瑞亚原版会自动生成 `.wld.bak` 备份文件。请检查您的世界存档目录：

`Documents\My Games\Terraria\Worlds`

将 `.wld.bak` 文件重命名为 `.wld`，尝试加载该备份。

## 预防措施

- 在进行大规模编辑前，始终使用 **另存为** 创建备份副本
- 在[设置](../configuration/settings.md)中开启**自动保存**
- 将重要的世界副本单独保存在另一个文件夹中
