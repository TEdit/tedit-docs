# 侧边栏面板

侧边栏面板位于编辑器最右侧。点击顶部的各个标签页可在不同面板之间自由切换。

## 可用面板一览

| 面板名称 | 主要功能与用途 |
|---|---|
| [世界属性](world-properties.md) | 世界名称、时间调节、击败Boss进度、入侵事件与 NPC |
| [调色板](palette.md) | 物块与墙壁选择器及独立遮罩设置 |
| [特殊图格](special-tiles.md) | 编辑宝箱物品、标牌文字、图格实体（人体模型、女性人体模型等） |
| [物体](sprites.md) | 浏览与放置家具、装饰等多格物体 |
| [剪贴板](clipboard.md) | 复制、浮动粘贴、导入与导出结构图 |
| [NPC 管理](npcs.md) | 城镇 NPC 增删、改名与快速追踪定位 |
| [世界分析](world-analysis.md) | 世界统计数据与各类物块总数透视 |
| [怪物图鉴](bestiary.md) | 怪物击杀计数统计与图鉴解锁数据编辑 |
| [旗帜](banners.md) | 怪物旗帜收集进度查看器 |
| [图格实体调试](tile-entity-debug.md) | 原始图格实体底层数据查看器 |
| [旅行模式能力](creative-powers.md) | 旅行模式专属设置与管理功能 |
| [筛选面板](filter.md) | 隐藏或调暗特定物块图层，使视野更清晰 |
| [查找面板](find.md) | 在整个世界中全局搜索物品、物块、墙壁和物体 |
| [脚本面板](scripting.md) | 编写并运行 JavaScript / Lua 自动化编辑脚本 |
