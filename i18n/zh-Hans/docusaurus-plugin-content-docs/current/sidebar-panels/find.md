# 查找面板

查找面板可以在整个世界中搜索特定的物品、物块、墙壁或物体。

![查找面板](/img/v5/sidebar-panels/sidebar-search-find.png)

## 搜索标签页

| 标签页 | 搜索目标 |
|---|---|
| **物品** | 宝箱内的物品 |
| **物块** | 已放置的物块类型 |
| **墙壁** | 墙壁类型 |
| **物体** | 多格家具与物体 |

## 使用方法

1. 选择对应的标签页（物品、物块、墙壁、物体）
2. 选择或输入您要寻找的目标
3. 点击 **搜索世界**
4. 结果将显示在下方列表中（最多显示 1,000 条结果）

## 高亮覆盖层

搜索完成后，TEdit 会自动在地图上高亮所有匹配结果。不匹配的物块会变暗并去饱和（使用与[筛选面板](filter.md)的调暗模式相同的着色器），使匹配的物块在视觉上突出显现。十字准星会标出当前选中的结果。

当您开始新搜索或清除结果时，高亮覆盖层会自动清除。

## 结果导航

- **上一个 / 下一个** — 在地图上的各个结果点位之间跳转。结果计数器会显示当前位置（例如："3 of 47"）。
- **导航时自动缩放** — 开启后，在跳转到每个结果时会自动缩放视角（默认关闭 — 仅平移视角）。
- **计算距离** — 按与出生点的距离对结果进行排序，并在每个结果旁显示距离数值。

:::tip 提示
可以使用查找面板定位包含特定物品的所有宝箱，或统计世界中存在多少某种类型的物块。
:::
