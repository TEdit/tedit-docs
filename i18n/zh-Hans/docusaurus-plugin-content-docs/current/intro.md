# TEdit 5 中文文档

:::tip 下载与获取
从 GitHub Releases 获取最新版 TEdit：[https://github.com/TEdit/Terraria-Map-Editor/releases/latest](https://github.com/TEdit/Terraria-Map-Editor/releases/latest)。
:::

TEdit 5 是对泰拉瑞亚地图编辑器的全新重构版本。你可以像在画板上绘画一样编辑世界——使用笔刷和填充工具放置物块、墙壁、液体和电线；编辑宝箱、标牌和 NPC；随心所欲打造属于你的史诗地牢、城堡、城镇和冒险地图。

![TEdit 5 编辑器](/img/v5/interface/TEdit_sNWvexY0S7.png)

## TEdit 5 全新特性

- **Fluent Design** — 采用现代化的 WPF-UI 界面，原生支持暗黑模式
- **脚本引擎** — 支持编写 JavaScript 或 Lua 脚本实现自动化编辑
- **查找面板** — 在整个世界中搜索物品、物块、墙壁和物体
- **筛选面板** — 隐藏或调暗特定物块类型，使编辑视野更加清晰
- **多语言支持** — 软件 UI 已内置支持 13 种语言
- **自动更新** — 基于 Velopack 提供稳定版、公测版与内测版更新通道
- **现代化设置中心** — 分类清晰、支持搜索的全新设置窗口
