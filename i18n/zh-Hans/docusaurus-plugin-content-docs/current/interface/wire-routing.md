# 电线布线系统

电线布线模式提供了类似于 CAD 绘图软件的“点对点点击式”绘制体验。不同于繁琐的徒手涂画，你只需在地图上点击一个起始锚点，再点击目标终点——编辑器就会自动在两点之间计算出规整平直的线路。

布线系统不仅适用于 **铅笔工具**（单根电线）和 **笔刷工具**（多线总线并行），还全面支持 **矿车轨道** 与 **平台** 绘制——轨道自动采用精细对角线走线，而平台在 45° 斜角走线下会自动组装正确的阶梯帧形态（踏板、纵梁、着陆转折段）。

## 进入与切换布线模式

| 快捷键 | 对应操作动作 |
|---|---|
| `Shift+W` | 循环切换布线模式：关闭 → 90° 直角弯折 → 45° 斜角切角 → 关闭 |
| `Shift+Q` | 循环切换方向优先级：自动 → 水平优先 → 垂直优先 → 自动 |
| `Escape` | 取消当前锁定的起始锚点（仍保留布线模式），或彻底退出布线模式 |

当选中 **电线**、**轨道** 或 **平台** 绘制模式时，布线系统均可激活。操作栏上的布线面板会实时显示当前的布线算法与方向偏好，底部状态栏也会同步指示。

## 电线颜色切换快捷键

在电线绘制模式下，随时按下键盘数字键即可快速开关对应颜色的电线：

| 快捷键 | 电线颜色 |
|---|---|
| `1` | 红色电线 |
| `2` | 蓝色电线 |
| `3` | 绿色电线 |
| `4` | 黄色电线 |

无论是否开启了布线模式，这组快捷键在电线图层下始终生效。

## 单线布线模式 (单线 — 配合铅笔工具)

选中 **铅笔工具** `[E]` 并使用 `Shift+W` 进入布线模式。

![电线布线](/img/v5/interface/wire-routing.png)

1. **第一次点击** — 确立起始锚点（地图上会亮起高亮标记）
2. **移动鼠标光标** — 画布上实时出现半透明的预览线路
3. **第二次点击** — 确认提交铺设该段电线，并将终点自动作为下一段的新锚点（连续链式）
4. **鼠标右键** — 取消布线当前锚点，不提交任何内容

锚点具备自动链式连接特性：提交当前线段后，终点立即成为下一段的新起点，方便连续绘制带折角的长距离走线。

### 连续链式模式

![链式电线](/img/v5/interface/chain-wire.png)

启用链式模式时（通过 `Shift+W` 切换），每次确认铺设的线段终点都会自动接力为下一段的起始锚点——形成连续的折线走线。若关闭链式模式，则每次点击只提交单条线段，不会自动接力。

链式模式同时适用于单线绘制（铅笔）与总线绘制（笔刷）。

### 走线算法模式

| 模式 | 走线形态 | 说明细节 |
|---|---|---|
| **直角弯头（90° Elbow）** | L 型直角 | 沿一个坐标轴单向直行，然后 90° 转角直达目标点 |
| **斜角切角（45° Miter）** | 平直–对角线–平直 | 先走平直段，经过 45° 阶梯斜角过渡段，再平直接入目标点 |

所有生成的线路都严格保持 **4 方向连通（4-connected）**——相邻物块必须共享一条边（绝无仅对角相连的虚空漏线），确保在泰拉瑞亚原版游戏中电路 100% 连通生效。

### 走向优先级覆盖

通过 `Shift+Q` 可以强制指定哪个轴向先走：

| 选项设置 | 逻辑行为 |
|---|---|
| **自动** | 当两点夹角大于 45°（较陡）时自动选择垂直优先，否则水平优先 |
| **水平优先** `↔` | 先走水平段，再垂直转角 |
| **垂直优先** `↕` | 先走垂直段，再水平转角 |

## 总线电线布线 (配合笔刷工具) {#bus-routing-brush-tool}

选中 **笔刷工具** `[B]`，将笔刷尺寸调整至大于 1×1，并使用 `Shift+W` 开启布线模式。

![总线布线](/img/v5/interface/bus-routing.png)

总线布线可**并排绘制多条平行的电线线路**，自动填满整个笔刷覆盖范围。电线根数和线路间距会根据笔刷的长宽自动计算分配。

1. **第一次点击** — 在笔刷中心确定总线起始锚点
2. **移动鼠标光标** — 实时预览多根平行线路的完整走线
3. **第二次点击** — 确认铺设所有总线线路，并继续链式接力

### 电线间距规则

无论是 90° 直角还是 45° 斜角总线，均采用 **2 格间距标准**（线路间留有 1 格空隙）。由于泰拉瑞亚原版中对角线接触的电线并不会导电相连，因此斜角过渡时不需要额外加大间距。

### 总线排布细节

- **线路总数** 由笔刷的宽高尺寸与安全间距决定
- 电线组在笔刷区域内**居中对齐**
- **起点位置** 自动排布在与鼠标运动方向相反的笔刷一侧边缘
- **终点位置** 沿目标端垂线方向展开，确保拐角处各线不会互相重叠或短路交叉
- 当笔刷为 **1×1 尺寸** 时，自动降级为与铅笔工具完全相同的单线布线模式

:::tip 技巧
使用方向覆盖（Shift+Q）可以控制总线优先水平还是优先垂直走线。这决定了电线从笔刷的哪条边出发，以及最终到达哪条边。
:::

## 矿车轨道与平台楼梯布线

布线系统同样原生扩展到了 **轨道** 和 **平台** 绘制中。

### 轨道布线

轨道模式在 45° 斜角铺设时采用精细的单格斜线——每一级斜向步进只占用单个物块，完美匹配泰拉瑞亚原版轨道的斜向拼接特性。启用 **隧道** 子模式时，预览图会以较暗的蒙版直观标出轨道上方即将挖空的隧道净空区域。

### 平台楼梯布线 {#platform-routing}

平台模式在 45° 斜角走线下采用阶梯走线，并根据几何位置自动匹配正确的平台物块帧：

| 构件角色 | 说明解释 |
|---|---|
| **踏板** | 阶梯踏步台面（楼梯每一步的受力上表面）— 包含 3 种随机自然变体 |
| **梯段纵梁** | 阶梯下底支撑面（阶梯台阶的背部斜面） |
| **顶部着陆平台** | 楼梯顶端与平直平台交界处的平滑过渡平台 |
| **底部着陆平台** | 楼梯底端与平直平台交界处的过渡平台 |
| **端盖** | 当楼梯紧挨实心物块时的端盖变体 |
| **单平台** | 纯垂直排布的平台构件 |

着陆过渡段会从楼梯连接处延伸进水平段 1 格，且阶梯的朝向（向右上还是向左上）会根据路径向量自动判断。

## 脚本 API 调用

布线系统同样全面开放给了 [脚本自动化 API](../advanced/api-reference.md#wire-routing)。你可以通过 `draw.routeWire()` 绘制单线，或通过 `draw.routeBus()` 绘制多根并行总线：

```javascript
// 绘制一条 90° 直角弯头的红色电线
draw.setWire(true, false, false, false);
draw.routeWire(100, 200, 150, 220, '90', 'h');

// 绘制 4 条并排平行的 45° 绿色总线
draw.setWire(false, false, true, false);
draw.routeBus(4, 100, 200, 200, 250, '45', 'auto');
```
