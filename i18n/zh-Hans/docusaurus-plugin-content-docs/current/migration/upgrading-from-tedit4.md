# 从 TEdit 4 升级

TEdit 5 是一次重大的重写，带来了现代化的界面与全新功能。以下是主要变化。

## 新特性

| 特性 | 说明 |
|---|---|
| **Fluent Design** | 基于 WPF-UI 构建的现代化暗黑模式界面 |
| **脚本引擎** | 支持完整世界 API 的 JavaScript 与 Lua 脚本引擎 |
| **查找面板** | 在世界中搜索物品、物块、墙壁、物体 |
| **筛选面板** | 隐藏或调暗特定物块图层 |
| **多语言支持** | 支持 13 种界面语言翻译 |
| **自动更新** | 内置支持 Stable/Beta/Alpha 通道的更新系统 |
| **现代化设置** | 支持搜索和分类管理的全新设置窗口 |
| **锤子工具** | 新增基于区域的锤子工具 |
| **世界分析** | 查看世界统计数据的侧边栏 |

## 界面变动

- **工具栏** — 工具保持一致，图标全新重绘。垂直工具栏依然位于左侧。
- **活动栏 → 操作栏** — 顶部选项栏经过重新设计，工作方式保持一致。
- **侧边栏工具 → 侧边栏面板** — 右侧面板改为标签页形式。新增面板（查找、筛选、脚本）。
- **设置** — 从 XML 配置文件迁移到支持搜索的现代化设置窗口。
- **插件 → 脚本** — 旧版插件系统已被脚本引擎取代。详见[脚本指南](../advanced/scripting-guide.md)。

## 运行时变化

| | TEdit 4 | TEdit 5 |
|---|---------|---------|
| **运行时框架** | .NET Framework 4.8 | .NET 10 |
| **DirectX** | DirectX 11 | DirectX 11 |
| **操作系统** | Windows 10 x64 | Windows 10/11 x64 |

## 结构图兼容性 {#schematics}

TEdit 5 可以打开来自 TEdit 4 的 `.TEditSch` 结构图文件。您现有的结构图无需任何修改即可正常使用。

## 设置迁移

TEdit 5 采用了新的设置格式。您在 TEdit 4 中的 `settings.xml` 不会自动迁移。请在新的“设置”窗口中重新配置您的偏好项。
