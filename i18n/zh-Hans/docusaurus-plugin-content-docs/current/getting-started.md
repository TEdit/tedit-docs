# 快速入门

:::danger 极重要提醒
**在进行任何编辑前，请务必先备份您的世界存档文件！**
:::

:::info 提示
请确保您已阅读过[安装与系统要求](install-requirements.md)。
:::

## 打开世界地图

1. 启动 `TEdit.exe`
2. 点击菜单栏 **文件 > 打开** 或使用快捷键 `Ctrl+O` 打开 `.wld` 世界文件
3. 泰拉瑞亚默认世界存档路径通常位于：
   - `Documents\My Games\Terraria\Worlds`

## 地图浏览与操作

| 操作动作 | 控制方式 |
|---|---|
| 平移视角 | 鼠标中键按住拖拽，或使用键盘方向键 |
| 缩放地图 | 滚动鼠标滚轮，或使用 `Ctrl+=` / `Ctrl+-` |

:::tip 技巧
缩放视角将紧随鼠标指针当前所在位置进行缩放——将鼠标对准想要放大的区域滚动滚轮即可。
:::

## 你的第一次编辑

1. 从[工具栏](interface/toolbar.md)中选择**铅笔**工具
2. 从[操作栏](interface/action-bar.md)中选择一种物块类型（例如：泥土块）
3. 在地图画布上单击鼠标左键开始放置物块
4. 通过 **文件 > 保存** 或 `Ctrl+S` 保存世界
