# 图片转结构图

TEdit 可以将图片文件转换为由游戏物块构成的像素画，供您粘贴到世界中。

## 操作流程

1. 点击菜单栏 **插件 > 图片转结构图**。
2. 选择一张图片文件（支持 PNG、JPG、BMP 等格式）。
3. TEdit 会自动将图片中的每个像素色彩映射到颜色最接近的泰拉瑞亚物块上。
4. 转换结果会自动载入到[剪贴板](../sidebar-panels/clipboard.md)中作为结构图。
5. 将其直接粘贴到世界中。

## 实用技巧

- **较小的图片效果更佳** — 100×100 像素的图片在地图上会变成 100×100 格物块
- **建议提前减少色彩** — 泰拉瑞亚原版物块的调色板颜色有限
- 线条清晰、对比鲜明的扁平像素画转换效果最好
- 可以使用**剪贴板**将生成的结构图导出保存，以便日后重复使用
