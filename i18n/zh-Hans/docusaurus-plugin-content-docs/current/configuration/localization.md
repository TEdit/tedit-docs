# 界面语言与本地化

TEdit 5 的用户界面支持 13 种语言，与泰拉瑞亚官方支持的语言完全一致。

## 切换语言

1. 打开 **编辑 > 设置**
2. 找到 **语言** 设置项
3. 从下拉菜单中选择您的语言
4. 重启 TEdit 以应用更改

## 支持的语言

| 语言 | 区域代码 |
|---|---|
| 自动（跟随系统默认） | — |
| 英语 (English) | en |
| 阿拉伯语 (Arabic) | ar-BH |
| 简体中文 (Chinese Simplified) | zh-Hans |
| 繁体中文 (Chinese Traditional) | zh-Hant |
| 法语 (French) | fr-FR |
| 德语 (German) | de-DE |
| 意大利语 (Italian) | it-IT |
| 日语 (Japanese) | ja-JP |
| 韩语 (Korean) | ko-KR |
| 波兰语 (Polish) | pl-PL |
| 巴西葡萄牙语 (Portuguese Brazil) | pt-BR |
| 俄语 (Russian) | ru-RU |
| 西班牙语 (Spanish) | es-ES |

:::info 提示
不同语言的翻译覆盖率可能有所不同。如果某些 UI 元素尚未翻译，将会自动回退显示为英文。
:::
