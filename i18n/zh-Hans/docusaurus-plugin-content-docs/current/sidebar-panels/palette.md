# 调色板

调色板面板提供了所有物块与墙壁的可视化分类浏览，以及用于控制绘制生效区域的遮罩配置。

## 物块选择器

![调色板 — 物块选择器](/img/v5/interface/palette-tile.png)

从分类列表中浏览并选择物块与墙壁。所选中的物块和墙壁将被铅笔、笔刷和填充工具在“物块/墙壁绘制模式”下直接使用。

- **搜索** — 按名称筛选物块或墙壁
- **物块选择器** — 点击设置当前激活的物块类型
- **墙壁选择器** — 点击设置当前激活的墙壁类型

选中的物块/墙壁 ID 也会同步显示在操作栏的下拉菜单中。调色板面板中的更改会实时反映在操作栏中，反之亦然。

## 遮罩 {#masks}

![调色板 — 遮罩](/img/v5/interface/palette-mask.png)

遮罩用于限制绘制操作生效的区域。调色板面板为物块和墙壁分别提供了独立的遮罩控制项。

### 物块遮罩

| 模式 | 效果说明 |
|---|---|
| **禁用遮罩** | 在任意区域均可绘制物块 |
| **仅编辑空白** | 仅在空白空间放置物块 |
| **仅编辑匹配项** | 仅替换与遮罩类型匹配的物块 |

从下拉菜单中设置物块遮罩类型——列表中包含所有可用物块类型。

### 墙壁遮罩

| 模式 | 效果说明 |
|---|---|
| **禁用遮罩** | 在任意区域均可绘制墙壁 |
| **仅编辑空白** | 仅在空白空间铺设墙壁 |
| **仅编辑匹配项** | 仅替换与遮罩类型匹配的墙壁 |

从下拉菜单中设置墙壁遮罩类型——列表中包含所有可用墙壁类型。

:::tip 提示
使用[吸管工具](../interface/toolbar.md#picker-tool-r)在地图上的物块上单击右键，可快速将其设置为遮罩类型。
:::

## 全部替换

![调色板 — 完整面板](/img/v5/sidebar-panels/palette-full.png)

在**遮罩选项**标签页底部，提供了两个批量替换按钮，用于在全图或选区内将匹配区域替换为选中的物块：

![批量替换按钮](/img/v5/sidebar-panels/palette-replace-all.png)

| 按钮 | 效果说明 |
|---|---|
| **全部替换** | 将整个地图上所有与当前遮罩匹配的物块/墙壁替换为所选的物块/墙壁 |
| **替换选区** | 仅在当前选区范围内进行替换 |

这些按钮依据当前激活的遮罩配置来确定匹配哪些物块或墙壁。将遮罩模式设为 **仅编辑匹配项** 并选择遮罩类型，然后点击其中一个替换按钮即可执行替换。

:::caution 警告
**全部替换** 会修改整个地图，属于大型操作。建议使用 **替换选区** 将修改限制在特定区域。
:::
