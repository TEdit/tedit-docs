# 物体

物体面板让您可以浏览并放置家具、装饰品以及各类多格物体。

![物体放置器](/img/v5/sidebar-panels/sidebar-sprite-placer.png)

## 使用方法

1. 从工具栏中选择[物体工具](../interface/toolbar.md#sprite-tool-t)（快捷键 `T`）
2. 打开“物体”侧边栏面板
3. 从下拉菜单中选择物块类型（如椅子、桌子、火把等）
4. 使用筛选框按名称搜索
5. 在网格中选择所需样式
6. 在地图上单击鼠标左键进行放置

## 绘制物体

- **单件物体** — 鼠标左键点击一次放置一个
- **1×1 物体**（草丛、平台等） — 点击并拖动可像铅笔工具一样连续笔触绘制。支持水平直线（右键拖动）与垂直直线（左键+右键同时拖动）绘制。

## 缩略图尺寸

使用物体网格顶部的**缩略图尺寸滑块**可以调节物体预览图的显示大小。向右拖动可放大缩略图（便于直观辨认样式），向左拖动可缩小缩略图（单屏显示更多物体）。

该滑块的设置会自动在会话间保持保存。

## 生物群系变体

某些物体拥有对应生物群系的变体（例如树木、植物、藤蔓）。当某种物体类型存在多种变体时，面板会按生物群系分组展示。选择对应的生物群系标签或变体分组，即可查看该组下的所有可用样式。
