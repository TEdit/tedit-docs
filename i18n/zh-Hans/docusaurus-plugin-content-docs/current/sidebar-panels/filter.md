# 筛选面板

筛选面板允许您隐藏或调暗特定的图层与物块类型，让您专注于当前正在编辑的内容。

![筛选面板](/img/v5/sidebar-panels/sidebar-filter.png)

## 筛选模式

| 模式 | 效果说明 |
|------|--------|
| **隐藏** | 被筛选的类型将完全不可见（透明隐藏） |
| **调暗** | 被筛选的类型将变暗并降低饱和度，使未被筛选的物块突出醒目 |

点击面板顶部的 **隐藏** 开关可在两种模式之间切换；关闭该开关时会自动启用 **调暗** 模式。

### 调暗与去饱和滑块

在调暗模式下，提供两个控制滑块调节筛选图层的视觉强度：

- **调暗** (0–100，默认 75) — 控制被筛选图层的暗化程度。数值越高，物块越暗。
- **去饱和** (0–100，默认 75) — 控制被筛选图层的色彩褪色程度。数值越高，越趋向黑白灰度。

这些滑块基于 GPU 着色器实时渲染，滑动时即可实时预览视觉效果。

## 背景模式

控制在应用筛选时地图背景的外观表现：

| 模式 | 视觉效果 |
|------|--------|
| **常规** | 渲染标准的地图背景 |
| **透明** | 背景完全透明 |
| **自定义** | 使用拾色器选择任意自定义背景色彩 |

## 筛选分类标签

选择需要参与筛选的具体图层类型：

- **物块** — 筛选特定物块类型
- **墙壁** — 筛选特定墙壁类型
- **液体** — 筛选水、熔岩、蜂蜜、微光
- **电线** — 筛选各种颜色的电线
- **物体** — 筛选家具、火把及各类多格装饰物体

## 使用步骤

1. 切换 **隐藏** 开关选择隐藏或调暗模式
2. 若使用调暗模式，根据需要调节 **调暗** 与 **去饱和** 滑块
3. 选择所需的 **背景模式**
4. 在各标签页中勾选需要筛选的对应项目
5. 点击 **应用** 生效
6. 点击 **禁用** 即可恢复常规全图显示视图

![筛选效果预览](/img/v5/sidebar-panels/sidebar-filter-preview.png)

:::tip 技巧
**筛选剪贴板** — 开启后，在进行剪贴板结构图粘贴时，浮动图层也会遵循当前激活的筛选规则。
:::

## 全图像素映射图

Pixelmap 功能可以将整张世界地图渲染为色彩编码的宏观分析图像。支持三种色彩模式：

| 色彩模式 | 说明描述 |
|------------|-------------|
| **常规** | 采用小地图标准物块色彩渲染——与游戏内小地图观感完全一致 |
| **生物群系** | 根据物块所属的生物群系进行着色（腐化、猩红、神圣、丛林、雪原、沙漠等）——便于直观透视环境感染扩散边界 |
| **高度分层** | 依据垂直 Y 坐标深度进行色彩渐变着色——从地表到地下再到洞穴层形成平滑渐变，地形地势起伏一目了然 |

在筛选面板中的 Pixelmap 分组下选定色彩模式，点击 **渲染** 即可生成视图。Pixelmap 属于快照渲染，编辑地图后再次点击**渲染**即可刷新。
