# 剪贴板

剪贴板将复制的地图选区存储为结构图。利用剪贴板可以复用建筑构造、导入泰拉瑞亚社区分享的结构图，或者将自己的作品导出为文件随时调用。

![剪贴板面板](/img/v5/sidebar-panels/sidebar-clipboard.png)

## 快捷操作速查

| 操作动作 | 快捷键 |
|---|---|
| 复制当前选区 | `Ctrl+C` |
| 粘贴最近一次复制的结构图 | `Ctrl+V` |
| 粘贴时在地图上放置 | 鼠标左键点击画布 |

## 复制结构图

1. 使用[选区工具](../interface/toolbar.md#selection-tool-s)框选地图上的目标建筑区域。
2. 按下 `Ctrl+C` — 选区内容将自动生成一份带缩略图的结构图保存在剪贴板面板中。

## 粘贴结构图

1. 在剪贴板中点击某个条目上的 **粘贴** 按钮，或直接按 `Ctrl+V`。
2. 在地图画布上单击鼠标左键，生成一个**浮动粘贴图层**。
3. 按照需求拖拽移动、拉伸缩放或旋转翻转（详见 [浮动粘贴详解](#floating-paste)）。
4. 按下 **Enter** 回车键或点击对勾确认正式写入世界，或按 **Esc** 键取消本次粘贴。

:::tip 技巧
`Ctrl+V` 默认粘贴最近一次复制的结构图。若要粘贴列表中的其他历史结构图，只需在侧边栏中点击该项上的 **粘贴** 按钮，后续 `Ctrl+V` 就会切换为该结构图。
:::

## 即时粘贴 {#instant-paste}

![即时粘贴](/img/v5/interface/instant-paste.png)

当启用 **即时粘贴** 开关时（在粘贴工具选项中开启），点击地图会立即将结构图正式写入，不会弹出半透明的浮动预览。这专为连续盖戳放置设计——您可以快速连续点击放置多个副本，无需每次按回车确认。

即时粘贴跳过浮动预览层：每次鼠标点击都会以光标处为基准直接将内容写入地图。

## 浮动粘贴 {#floating-paste}

在未开启即时粘贴的情况下，点击画布放置粘贴时会生成一个带虚线外框和控制手柄的浮动预览图层。在您确认接受之前，该图层**尚未正式写入世界**——您可以先随意调整位置、比例和朝向。

![浮动粘贴](/img/v5/interface/paste.png)

### 移动对齐

在浮动图层内部任意位置按住鼠标左键并拖拽，即可平移图层。当光标悬停在图层内部时会变为移动十字箭头。您也可以在操作栏的 X、Y 文本框中直接手动输入绝对坐标。

### 尺寸拉伸缩放

拖拽外边框上的 8 个控制手柄即可调整尺寸：

| 控制手柄 | 缩放效果 |
|---|---|
| 四角手柄 | 同时等比或自由拉伸宽度与高度 |
| 上 / 下边缘手柄 | 仅调整垂直高度 |
| 左 / 右边缘手柄 | 仅调整水平宽度 |

光标悬停在手柄上时会变为对应朝向的双向箭头。您也可以在操作栏的 W（宽）、H（高）文本框中输入数值。

缩放采用**最近邻** 物块重采样算法——通过复制或裁剪物块来填充新尺寸。在拉伸缩放期间，物体（家具、装饰）会被自动剥离；原始物块上的斜坡和半砖状态会得到保留，新插值的填充物块将以完整物块呈现。

### 几何变换快捷键

| 快捷键 | 对应动作 |
|---|---|
| `Ctrl+Q` | 顺时针旋转 90° |
| `Ctrl+Shift+Q` | 逆时针旋转 90° |
| `Ctrl+H` | 水平镜像翻转 |
| `Ctrl+Shift+H` | 垂直镜像翻转 |

### 确认接受 / 取消放弃

| 操作动作 | 触发效果 |
|---|---|
| **Enter** 键 或 绿色对勾按钮 | 确认将粘贴图层正式提交写入世界地图 |
| **Esc** 键 或 红色关闭按钮 | 放弃本次粘贴并清空浮动图层 |

## 导入与导出

- **导入结构图** — 从磁盘加载 `.TEditSch` 结构图文件
- **导出** — 将结构图保存为 `.TEditSch` 文件，便于分享或日后复用
- **移除** — 从剪贴板中删除选中的单份结构图
- **清空剪贴板** — 一键清理剪贴板中加载的所有结构图
