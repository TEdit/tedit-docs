# 界面概览

TEdit 5 采用了基于 WPF-UI 构建的现代化 Fluent Design 界面。

![TEdit 5 界面](/img/v5/interface/TEdit_sNWvexY0S7.png)

## 布局区域

编辑器划分为以下几个主要区域：

| 区域 | 位置 | 功能用途 |
|---|---|---|
| **菜单栏** | 顶部 | 文件、编辑、图层、插件、帮助 |
| **操作栏** | 菜单栏下方 | 绘制模式、笔刷设置、物块/墙壁选择器等 |
| **工具栏** | 左侧 | 工具切换（箭头、铅笔、笔刷等） |
| **地图画布** | 中央核心区 | 世界地图编辑画布——所有绘制与编辑都在这里发生 |
| **侧边栏面板** | 右侧 | 剪贴板、世界属性、查找、筛选、脚本等 |
| **状态栏** | 底部 | 鼠标指针坐标、当前指向物块信息、缩放倍率 |

## 菜单栏详解

### 文件

![文件菜单](/img/v5/interface/menu-file.png)

用于打开、保存和导出世界存档。提供最近打开的文件列表以供快速加载。

### 编辑

![编辑菜单](/img/v5/interface/menu-edit.png)

撤销、重做、复制、粘贴、选区操作，以及进入设置中心。

### 图层

![图层菜单](/img/v5/interface/menu-layers.png)

切换各渲染图层的显示与隐藏状态（物块、墙壁、电线、液体等）。

**世界边界可视化** — 在“图层”菜单中启用 **显示世界边界**，即可在地图上叠加显示生物群系分界线。它会在不同生物群系（腐化、猩红、神圣、丛林、沙漠、雪原等）之间绘制显眼的标记线条，方便您直观查看环境分布并据此规划编辑。再次点击该选项即可关闭并返回常规视图。

### 插件

![插件菜单](/img/v5/interface/menu-plugins.png)

内置的插件功能和便捷辅助工具。

### 帮助

![帮助菜单](/img/v5/interface/menu-help.png)

关于软件、外部链接和检查更新等信息。

## 深色模式

TEdit 5 默认启用深色主题。你可以在 [设置中心](../configuration/settings.md) 中随时切换深色/浅色模式。
