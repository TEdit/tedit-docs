# 笔刷设置

当使用笔刷、环境演变或敲锤工具时，笔刷设置面板会显示在操作栏中。

![笔刷大小选项](/img/v5/interface/brush-size-options.png)

## 尺寸

- **宽度** — 1 至 400 格物块（默认：20）
- **高度** — 1 至 400 格物块（默认：20）
- **锁定宽高** — 锁定宽高比例，使其保持相等

可以使用滑块调节，也可以直接输入数字。

## 形状

| 形状 | 说明 |
|---|---|
| **方形** | 矩形/方形笔刷 |
| **椭圆** | 椭圆/圆形笔刷 |
| **向右倾斜** | 向右倾斜的对角线笔刷 |
| **向左倾斜** | 向左倾斜的对角线笔刷 |
| **星形** | 五角星形笔刷 |
| **三角形** | 三角形笔刷 |
| **月牙形** | 月牙形笔刷 |
| **圆环形** | 环形笔刷（外圈填充，中心中空） |

## 形状变换

选定形状后，您可以对其应用变换：

| 变换方式 | 说明 |
|---|---|
| **旋转** | 按设定度数旋转形状 |
| **水平翻转** | 左右镜像翻转形状 |
| **垂直翻转** | 上下镜像翻转形状 |

形状变换在处理三角形和月牙等非对称形状时尤为实用。

## 线框模式

启用线框模式后，仅绘制形状的边缘边框，生成空心形状。

- **线框粗细** — 1 到最小尺寸的一半
- 勾选复选框开启或关闭线框模式

## 喷枪模式

喷枪模式使笔刷按照设定的时间间隔持续绘制，而不仅在鼠标移动时绘制。这会产生类似喷漆的效果——在原地按住鼠标即可按照设定速率持续绘制。

- **启用** — 勾选 Spray 复选框开启或关闭喷射定时器
- **间隔** — 设置两次喷射之间的间隔毫秒数（数值越小 = 喷射越快）

:::tip 技巧
喷枪模式非常适合用于创建随机分布或具质感的效果——建议与遮罩配合使用以限制绘制落点。
:::
