# 设置中心

通过菜单栏打开设置：**编辑 > 设置** 或使用快捷键。

![设置中心窗口](/img/v5/configuration/settings.png)

TEdit 5 拥有全新重构的设置窗口，支持实时搜索与分类折叠管理。

## 使用技巧

- **搜索** — 在顶部搜索框中直接输入设置项名称即可快速查找
- **分类** — 所有设置按模块归纳在可折叠的分组中
- **保存 / 取消** — 应用保存更改或放弃还原

## 设置分类详解

### 通用设置

控制软件全局行为与更新偏好。

![通用设置](/img/v5/configuration/settings-general-and-update-channel.png)

| 设置项 | 说明解释 |
|---|---|
| **自动保存** | 定期在后台自动保存当前世界 |
| **检查更新** | 启动软件时自动检查是否有新版本 |
| **更新通道** | 选择更新通道：稳定版、公测版或内测版 |
| **语言** | 软件界面语言（详见 [多语言设置](localization.md)） |

### 隐私与路径 {#privacy--paths}

![隐私与路径设置](/img/v5/configuration/settings-privacy-paths.png)

| 设置项 | 说明解释 |
|---|---|
| **错误反馈** | 发生异常时发送匿名崩溃报告以协助改进 TEdit。报告不包含任何个人隐私或世界地图数据，仅包含异常堆栈信息与基本系统信息。 |
| **游戏路径** | 泰拉瑞亚 Content 资源文件夹路径（用于物体贴图渲染） |
| **Steam User ID** | 覆盖自动侦测到的 Steam 用户 ID，精确定位对应的世界存档目录。当一台电脑上有多个 Steam 账号或路径异常时非常有效。 |
| **最大备份数** | 每个世界保存的 `.TEdit` 循环备份文件上限（默认：10 份）。详见 [存档与备份](saves-and-backups.md#automatic-tedit-backups)。 |

:::info
错误报告需用户主动选择开启（默认关闭）。您可以随时关闭该选项，所收集信息仅严格用于排查与修复程序缺陷。
:::

### 渲染与图层

![渲染设置](/img/v5/configuration/settings-rendering-layers.png)

| 设置项 | 说明解释 |
|---|---|
| **写实色彩** | 使用写实物块色彩代替小地图颜色 |
| **材质显示阈值** | 开始显示物体贴图的缩放级别 |
| **物体缩略图尺寸** | 侧边栏中物体缩略图的预览尺寸 |
