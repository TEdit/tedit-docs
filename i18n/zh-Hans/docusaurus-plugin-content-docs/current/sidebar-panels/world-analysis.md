# 世界分析

世界分析面板提供关于您世界的统计信息。

![世界分析](/img/v5/sidebar-panels/sidebar-world-analysis.png)

## 功能特性

- **物块数量** — 统计每种物块类型的存在数量
- **生物群系分布** — 各生物群系的范围与占比
- **宝箱物品** — 所有宝箱内物品的汇总一览
- **NPC 状态** — 哪些 NPC 存在以及它们所在的位置

:::tip 提示
可以将世界分析面板与[查找面板](find.md)配合使用，以定位在统计中发现的特定物品或物块。
:::
