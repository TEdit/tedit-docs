# 操作栏

操作栏位于顶部菜单栏的正下方，它的内容会根据当前选中的工具动态变化。它包含了绘制模式选择、笔刷属性设置、物块/墙壁拾取器以及特定工具的配置选项。

![操作栏](/img/v5/interface/brush-tile-mode-options.png)

## 组成组件

根据当前激活的工具，操作栏会显示对应的设置面板：

| 面板 | 显示时机 | 功能用途 |
|---|---|---|
| [绘制模式](paint-mode.md) | 铅笔、笔刷、填充工具激活时 | 选择当前绘制的目标类型（物块、墙壁、电线、液体、轨道） |
| [笔刷设置](brush-settings.md) | 笔刷、环境演变、锤子工具激活时 | 调整笔刷大小、几何形状以及描边轮廓 |
| 环境演变 | 环境演变工具激活时 | 选择目标生物群系及转换选项 |
| NPC 选择器 | 点位选择工具激活时 | 选择要生成的生成点或 NPC 房间入住点 |

详情请参阅各链接的专门说明文档。
