# 状态栏

状态栏位于编辑器最底部，实时显示鼠标光标当前所指区域的上下文属性。

![状态栏](/img/v5/interface/status-bar.png)

## 显示信息一览

| 字段 | 说明解释 |
|---|---|
| **坐标** | 鼠标光标所在处的 X、Y 坐标（以物块格为单位） |
| **物块** | 光标所在处的物块类型名称及数字 ID |
| **墙壁** | 光标所在处的背景墙类型名称及数字 ID |
| **油漆** | 应用于该物块/墙壁上的涂料油漆颜色 |
| **选区** | 当前框选区域的宽高格数（若选区激活） |
| **缩放** | 当前地图画面的缩放级别 |

当你在地图上移动光标时，状态栏会实时刷新。配合箭头工具使用时，非常适合在不修改任何物块的前提下直接巡检地图细节。
