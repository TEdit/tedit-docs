# 自动更新

TEdit 5 采用 Velopack 实现直接从 GitHub Releases 进行程序自动更新。

## 更新通道

| 通道 | 说明描述 |
|---|---|
| **稳定版** | 经过充分测试的正式发行版 — 推荐绝大多数用户使用 |
| **公测版** | 包含前瞻新特性的预览版，可能包含少量非致命小 Bug |
| **内测版** | 最前沿的先锋测试版，可能不够稳定 |

## 运作方式

1. 启动软件时，TEdit 会在后台自动检查是否有新版本（若开启了更新检查）。
2. 若有可用更新，将提示您是否下载。
3. 下载完成后，点击 **应用并重启** 即可完成安装。

## 切换更新通道

1. 点击菜单栏 **编辑 > 设置**。
2. 找到 **更新通道** 设置项。
3. 在下拉菜单中选择 Stable、Beta 或 Alpha。
4. TEdit 随后便会在所选通道中检查更新版本。

:::info
从高版本通道（如 Alpha/Beta）降级切回低版本通道（如 Stable）时，若当前版本高于稳定版，可能需要执行一次降级覆盖安装。
:::

## 彻底关闭自动更新

在设置中将 **检查更新** 开关关闭，即可彻底禁用启动时的自动更新检测。您随时可以在 [GitHub Releases](https://github.com/TEdit/Terraria-Map-Editor/releases) 页面手动下载新版本。
