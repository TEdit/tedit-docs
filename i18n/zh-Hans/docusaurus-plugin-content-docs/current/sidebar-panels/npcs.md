# 城镇 NPC

NPC 面板让您可以管理世界中的城镇 NPC——添加或移除它们、编辑显示名称、切换微光或派对状态，并快速定位它们在地图上的位置。

![NPC 编辑器](/img/v5/sidebar-panels/sidebar-npc-editor.png)

## 搜索筛选

使用面板顶部的 **搜索** 框可按名称筛选 NPC。该筛选器匹配 NPC 的默认类型名称（如 "Nurse"（护士）、"Merchant"（商人）），不区分大小写。

## 添加与移除 NPC

- 点击尚未存在于地图上的 NPC 旁的 **+** 按钮，将其添加在世界出生点位置。
- 点击已存在于地图上的 NPC 旁的 **-** 按钮，将其从世界中移除。

## 编辑 NPC 属性

当某个 NPC 位于地图上时，提供以下选项：

- **显示名称** — 编辑游戏内显示在该 NPC 头顶的自定义名称。
- **微光形态** — 切换该 NPC 是否已处于微光形态（仅适用于支持微光形态的 NPC）。
- **派对状态** — 切换该 NPC 当前是否处于派对状态。
- **变体选择器** — 对于拥有多种外观变体的 NPC（如城镇宠物），可通过下拉菜单选择使用哪种外观变体。

## 跳转至位置

右键单击地图上存在的任意 NPC，地图将立即放大并平移居中到该 NPC 的当前位置。

:::tip 提示
若要移动 NPC 的住宅位置，请在地图上使用[点位工具](../interface/toolbar.md#point-tool-p)。
:::
