# 特殊图格

使用[箭头工具](../interface/toolbar.md#arrow-tool-a)在特殊图格上**右键单击**，即可在侧边栏中打开其专属编辑器。

## 宝箱编辑器

编辑宝箱内容物——添加、移除或重新排列物品。每个物品槽位均显示物品名称、堆叠数量和修饰语。

![宝箱编辑器](/img/v5/sidebar-panels/sidebar-chest-editor-open.png)

**全部清空** — 点击 **全部清空** 按钮可一次性清空宝箱内每个槽位中的所有物品。适合在填入新物品之前快速清空宝箱。

## 标牌编辑器

编辑标牌和墓碑的文本内容。

## 人体模型编辑器

为人体模型与女性人体模型装备盔甲与时装物品。

![人体模型编辑器](/img/v5/sidebar-panels/sidebar-mannequin-editor.png)

## 人体模型（Display Doll）编辑器

人体模型（内部名称 Display Doll，在部分语境下也称 mannequin）除装备槽位外，还支持**姿态**编辑。

用箭头工具右键点击人体模型可打开其编辑器。除了装备盔甲和时装物品外，还可以为其选择一种**姿态**：

- 从姿态下拉菜单中选择可用的姿态
- 选择姿态后，世界视图中的人体模型外观帧会即时更新

这样就能在装饰性建筑中让人体模型摆出不同的姿态。
