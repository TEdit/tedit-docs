# 绘制模式

绘制模式下拉菜单决定了铅笔、笔刷和填充工具具体影响哪一个图层。切换模式可对不同图层元素进行绘制。

## 物块与墙壁模式

![物块模式](/img/v5/interface/brush-tile-mode-options.png)

默认的绘制模式。在下拉框中选择要绘制的物块类型和/或背景墙类型。每个选项旁边均标有对应的内部数字 ID。

**橡皮擦开关** — 激活时（高亮显示），绘制行为将变为擦除物块/墙壁，而不是放置。

### 物块调色板

![调色板 — 物块选择器](/img/v5/interface/palette-tile.png)

操作栏中的选择框可以快速选定当前物块和墙壁类型。右侧的 [调色板面板](../sidebar-panels/palette.md) 则提供了更直观完整的物块与墙壁可视化网格，支持搜索与分类筛选。

### 遮罩蒙版 {#masks}

![调色板 — 遮罩](/img/v5/interface/palette-mask.png)

遮罩用于精准控制绘制行为的**生效范围**：

| 遮罩模式 | 实际效果 |
|---|---|
| **禁用遮罩** | 无限制，在任意区域均可绘制 |
| **仅编辑空白** | 仅在空白无物块/空气区域生效绘制 |
| **仅编辑匹配项** | 仅在覆盖匹配遮罩指定类型的物块/墙壁时才生效替换 |

在遮罩下拉框中设置遮罩类型——其列表与主选择器相同。物块遮罩与墙壁遮罩可以在 [调色板面板](../sidebar-panels/palette.md) 中完全独立配置。

### 涂料与涂层

你可以为物块和墙壁涂刷不同颜色的油漆，并应用特殊涂层：**回声涂料**、**夜明涂料** 与 **全亮涂料**。

### 反色漆

泰拉瑞亚原版中的 **反色漆**（ID: 30）会反转物块与墙壁的颜色。TEdit 5 通过专用的 GPU 着色器反转 RGB 通道并保留透明度，因此涂有反色漆的物块在编辑器画布上能与游戏内观感一致。

## 电线模式 {#wire-mode}

![电线模式](/img/v5/interface/brush-wire-mode-options.png)

放置或拆除电线。支持多选同时绘制的电线颜色：红色、蓝色、绿色、黄色。在该模式下还可以同步放置促动器。

按下 `Shift+W` 可启用 [电线布线模式](wire-routing.md)，实现 CAD 风格的点击式 90° 与 45° 自动规整排线。使用键盘数字键 `1`–`4` 可快速开关对应颜色的电线。

## 液体模式

![液体模式](/img/v5/interface/brush-liquid-mode-options.png)

放置或移除世界中的各类液体：水、熔岩、蜂蜜、微光。

## 平台模式

放置各类平台，并支持智能楼梯形态自动适配。平台模式原生支持 [布线系统](wire-routing.md)（快捷键 `Shift+W`）实现点击式平台铺设。

| 操作动作 | 触发效果 |
|---|---|
| 常规涂抹 | 放置单个独立平台 |
| `Shift+W` | 启用布线模式，实现点击起始点与终点的直线快速铺梯 |

在 45° 斜角铺设下，平台会自动适配正确的楼梯外观状态——踏板过渡、梯段纵梁以及平直平台连接处的着陆台外观。楼梯朝向与样式变体全自动智能分配，平台材质可在操作栏中自由选择。

详见 [布线系统 — 平台楼梯布线](wire-routing.md#platform-routing)。

## 矿车轨道模式

![轨道模式](/img/v5/interface/brush-track-mode-options.png)

铺设矿车铁轨及相关构件：

| 轨道类型 | 功能描述 |
|---|---|
| **Track** | 标准矿车铁轨 |
| **Booster** | 提速加速铁轨 |
| **Pressure Plate** | 轨道感应压力板 |
| **Hammer** | 循环切换轨道交叉岔路走向 |

### 轨道子模式

提供两种实用的自动化铺设子模式：

| 子模式 | 功能描述 |
|---|---|
| **隧道模式** | 在铺设铁轨的同时自动开凿隧道——自动挖空轨道上下方的空间，为矿车通行留出畅通空间 |
| **平滑模式** | 自动使用柔和弯道过渡替换生硬折角，生成流畅自然的铁路线路 |

在轨道模式激活时，可在操作栏的轨道选项中切换子模式。

轨道模式同样支持使用 `Shift+W` 触发 [布线铺设](wire-routing.md)。其 45° 斜角走线严格遵循泰拉瑞亚原生轨道的单格斜向逻辑。当启用 **Tunnel** 子模式时，铁轨上方要清理的隧道空间会在画布上以暗色蒙版进行实时预览。

## 物体模式

![物体模式](/img/v5/interface/brush-sprite-mode-options.png)

配合物体工具用于放置多格物体。可在[物体面板](../sidebar-panels/sprites.md)中选择要放置的具体物体。

### 为已有物体涂色与应用属性

铅笔和笔刷工具可以在不破坏原有家具的前提下直接为其附加属性。在物体模式下将**橡皮擦关闭**，涂抹已有物体即可应用：

- **物块油漆颜色** — 为物体的物块着色
- **墙壁油漆颜色** — 为物体后方的墙壁着色
- **涂料涂层** — 应用回声涂料（隐形）与夜明涂料（全亮）
- **促动器** — 切换促动器状态
- **虚化状态** — 切换虚化状态

这让您可以使用笔刷快速为大量已放置的物体上色或应用涂料，而无需重新放置它们。
